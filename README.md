# BÀI THỰC HÀNH 05: TẠO, QUẢN LÝ VÀ CHIA SẺ NỘI DUNG SỐ

## 1. Mô tả nội dung
Tài liệu và bài tập thực hành về:
* Tìm kiếm, lọc và quản lý dữ liệu số trong học tập.
* Giao tiếp, hợp tác trực tuyến theo quy tắc ứng xử.
* Tạo, chỉnh sửa nội dung số (văn bản, đa phương tiện, mã nguồn) và áp dụng bản quyền.
* Sử dụng công cụ AI minh bạch, đúng đạo đức.

## 2. Công cụ sử dụng
* **Phần mềm & Nền tảng:** Google Docs/Sheets, Canva, CapCut, GitHub, GitHub Desktop, Microsoft Teams, Microsoft Word/Excel/PowerPoint.
* **Trình duyệt web:** Google Chrome / Mozilla Firefox.

## 3. Trích dẫn nguồn
1. Bộ GD&ĐT (2025), *Khung năng lực số*.
2. JRC (2022), *DigComp 2.2: The Digital Competence Framework for Citizens*.
3. Google (2025), *Prompt Engineering Guide*.
4. Creative Commons, *Giấy phép bản quyền* ([creativecommons.org](https://creativecommons.org)).

## 4. Giấy phép bản quyền
Phát hành theo giấy phép **CC BY 4.0** (Creative Commons Attribution 4.0 International).

* **Bạn được phép:** Chia sẻ và chuyển thể cho mọi mục đích (commercial & non-commercial).
* **Điều kiện:** Phải ghi công tác giả gốc và chỉ ra các thay đổi (nếu có).
